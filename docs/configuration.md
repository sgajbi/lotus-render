# lotus-render Configuration

The authoritative configuration reference is the wiki page
**[Configuration](https://github.com/sgajbi/lotus-render/wiki/Configuration)**, authored in this
repository at [`wiki/Configuration.md`](../wiki/Configuration.md).

It covers every `LOTUS_RENDER_` setting and its default, the startup validations that reject an
invalid combination, the HTTP boundary rules, the Docker Compose deployment overrides, and the
secret-handling rule for this service.

This file intentionally keeps only this pointer so a second settings table cannot drift away from
the first.
